درباره من

سلام، من یک برنامه‌نویس جنگو هستم که به طراحی و توسعه وب‌اپلیکیشن‌های تمیز، سریع و کاربردی علاقه دارم.

تمرکز اصلی من روی توسعه بک‌اند با Django و Python است و در کنار آن با مفاهیمی مثل طراحی دیتابیس، REST API، احراز هویت کاربران و پیاده‌سازی پروژه‌های واقعی وب هم کار کرده‌ام.

همیشه سعی می‌کنم کدی بنویسم که هم خوانا باشد و هم قابل توسعه. یادگیری مداوم، حل مسئله و ساختن پروژه‌های کاربردی بخش مهمی از مسیر حرفه‌ای من است.

Python Django REST API Bootstrap HTML/CSS SQLite / PostgreSQL

مهارت‌های من

  • توسعه وب با Django
  • طراحی و مدیریت دیتابیس
  • ساخت API با Django REST Framework
  • پیاده‌سازی پنل مدیریت
  • کار با Bootstrap و قالب‌های واکنش‌گرا

ویژگی‌های کاری من

  • کدنویسی تمیز و قابل نگهداری
  • توجه به جزئیات
  • یادگیری سریع تکنولوژی‌های جدید
  • حل مسئله و تحلیل نیاز پروژه
  • تعهد به کیفیت و زمان‌بندی

اهداف من

هدف من این است که به عنوان یک توسعه‌دهنده حرفه‌ای جنگو، در ساخت پروژه‌های واقعی، مقیاس‌پذیر و ارزشمند مشارکت کنم و هر روز مهارت‌های فنی و تجربی خودم را ارتقا بدهم.
